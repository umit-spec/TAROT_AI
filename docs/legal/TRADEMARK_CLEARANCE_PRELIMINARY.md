## What this document is, and is not

This is a **general internet due-diligence pass**, not a professional
trademark search. Per CRG-1's own governing instruction, a generic web
search must not be treated as a completed trademark search, and this
document does not do so. Specifically:

- **TÜRKPATENT** (`turkpatent.gov.tr`, "Marka Sorgulama" / e-Devlet
  portal) was **identified** as the correct official Turkish registry
  search system via web search, but **no interactive query was actually
  executed** against it in this session — this environment has no
  authenticated or interactive browser session to operate that portal's
  search form.
- **WIPO Global Brand Database** (`wipo.int/en/web/global-brand-database`)
  was similarly **identified**, not **queried** — same limitation.
- **EUIPO TMview** was similarly **identified**, not **queried**.
- What *was* done: general web search (`WebSearch`) for the literal
  string "Insight Engine" in software/app/brand contexts, and for
  existing Turkish tarot/fal applications, to surface any obvious,
  already-public name collision. This is a first, low-cost filter only.

## Findings

### "Insight Engine" — general web presence

No tarot, fal, wellness, or reflection-app product called "Insight
Engine" was found in general web search. The term appears used
generically and descriptively in the **enterprise search / business
intelligence software category** ("insight engine" as a category name
for tools like Coveo, Attivio, Glean, Mindbreeze) — a materially
different market and, most likely, different Nice class(es) than a
consumer tarot/wellness app. One adjacent, unrelated brand, "Trademark
Engine" (a US trademark-filing service), was also found — different
product category, low direct confusion risk, but noted since it shares
the "[Word] Engine" naming pattern in a legal/professional-services
space.

### Existing Turkish tarot/fal app landscape

Search surfaced multiple existing Turkish-market tarot/fal apps: "Tarot
Falı," "Tarotify," "Falkolik," "Faladdin (FalaBak)," "Kaave." All use
generic Turkish descriptive naming ("tarot," "fal," "kahve falı") rather
than an "Insight Engine"-style brand name. No name collision with
"Insight Engine" or an obvious Turkish equivalent was found among these.
This does not rule out a registered-but-unused mark, a mark used only in
a different channel, or a mark not indexed by general web search — only
a professional database search resolves that.

### Nice classification — preliminary notes only, not a filing recommendation

A tarot/AI-narration reflection product plausibly touches:

- **Class 9** — downloadable software / mobile application.
- **Class 41** — entertainment services, "providing online... information
  in the field of... entertainment," which is where many
  horoscope/tarot/wellness-adjacent digital services are actually
  classified.
- **Class 42** — SaaS / software-as-a-service, if the product is
  positioned primarily as a software platform rather than an
  entertainment service.

**Class 44 (medical/therapy/psychological services) is deliberately NOT
recommended here**, and should not be treated as a candidate filing
class by anyone reading this document. The product's own governed copy
explicitly disclaims medical/therapy framing (see
`docs/legal/PRODUCT_CLAIMS_AUDIT.md`); filing in Class 44 would work
directly against that positioning and could itself create the
"health service" framing risk the product is trying to avoid. If
counsel identifies a need to file defensively in a class near 44, that
should be their explicit, reasoned call — not an inference from this
document.

## Product-name decision (preliminary, not a legal verdict)

**KEEP PENDING CLEARANCE.**

No collision was found in general web search, so there is no basis to
recommend RENAME at this time. Equally, no professional database search
was performed, so there is no basis to declare the name cleared. The
name should remain provisional until a professional search or counsel
opinion is obtained, and the product's actual Turkish-facing brand name
(if different from "Insight Engine") should be identified and searched
specifically, not just the English project name.
