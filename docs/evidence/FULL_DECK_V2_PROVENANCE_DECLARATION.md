## 2. Recorded production chain

Based on the project production record available at preparation time:

1. Ümit Karakeleş directed the visual brief and iterative card production.
2. Card images were generated using OpenAI ChatGPT image generation.
3. The brief used an original project visual language: dark obsidian/deep-violet surfaces, antique-gold framing and celestial/gothic editorial ornament.
4. No named artist style, existing commercial tarot deck, entertainment franchise or real-person likeness was knowingly requested as the source identity of the deck.
5. The user selected and approved outputs through iterative review.
6. Four King cards were mechanically separated/cropped from a generated four-card composition; this is recorded as a production transformation, not a third-party source.
7. The resulting files were organised/stored in Canva as uploaded User Content.
8. No Canva Licensed Content is intended to be embedded in the source card artwork. Final Canva designs still require an element-level audit before integration.
