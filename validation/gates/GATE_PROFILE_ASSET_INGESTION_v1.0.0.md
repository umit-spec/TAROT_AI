## Nine-Gate Framework for Asset Ingestion

This gate profile defines independent, verifiable criteria for asset quality before production integration.

### GATE 1: Canonical Mapping Integrity

**Requirement:** All 22 cards correctly numbered 0-21 with no duplicates, gaps, or swaps.

**Verification Method:**
- Extract all card IDs from registry
- Verify 22 unique IDs in range 0-21
- Confirm Strength=08 (not 11)
- Confirm Justice=11 (not 08)
- Confirm Tower=16 (not 17)
- Confirm Star=17 (not 16)

**Evidence:** `_extraction_manifest.json`, `CARD_REGISTRY.json`, `canonical_names.py`

**Acceptance Criteria:** ✓ PASS (all 22 cards verified, no swaps detected)

### GATE 2: File Naming Consistency

**Requirement:** All asset files follow canonical ID format: `NN-cardname` (not `NN-the-cardname`).

- Verify all HQ files: `00-fool-hq.webp` through `21-world-hq.webp` (22 total)

**Evidence:** File listing, git commit `024fee7` (66 renames tracked)

### GATE 3: Extraction Reproducibility

**Requirement:** Assets can be regenerated byte-identically from source montage.

**Verification Method:**
- Extract source montage SHA256: `b3e12d6733e621819a6a94949cdc7945fac445615fdfbda86c8ba7874199feb6`
- Locate crop configuration: `tools/assets/config/major_arcana_crops.json`
- Re-run: `python3 tools/assets/extract_major_arcana.py [source] [config] [output]`
- Compare output checksums against manifest: `_extraction_manifest.json`

**Evidence:** 
- Source checksum in manifest
- Crop coordinates preserved (22 cards × 4 coordinates = 88 values)
- Output checksums recorded for web and HQ formats (44 checksums total)
- Extraction script: `tools/assets/extract_major_arcana.py`

**Acceptance Criteria:** ⏳ PENDING Red Team reproducibility audit

### GATE 5: Asset Technical Specifications

**Requirement:** Web and HQ assets meet dimension, format, and file size targets.

**Verification Method:**

**Web Format (512×768):**
- Dimension check: all 22 images ≤ 512×768
- Format: WebP with quality 85
- File size: 5-20 KB (acceptable range for lossy compression)
- Magic bytes: RIFF...WEBP header present

**HQ Format (currently 2048×3072):**
- Dimension check: all 22 images = 2048×3072
- Format: WebP with quality 90
- File size: 15-100 KB (due to interpolation upscale)
- **NOTE:** Currently interpolated upscale (9.77x), not native high-res
- Alternative: Recommend 1024×1536 true high-res in Phase 2

**Evidence:** Manifest file sizes, WebP validation, optional: image dimension parsing

**Acceptance Criteria:** ⏳ PENDING format validation
