# Insight Engine — Major Arcana V1

This package contains 22 upright-only Major Arcana card faces and one shared card back.

- Production format: WebP
- Source dimensions: 1024 × 1536
- Palette: obsidian black, deep violet, antique gold
- Provenance: project-generated with OpenAI image generation
- Canva design IDs and SHA-256 checksums are recorded in `asset-manifest.json`

## Gates

Visual production is complete. Application integration, automated visual QA, accessibility review and external-commercialization legal review remain separate release gates.
